* 追求财富，而不是金钱或地位。财富是在你睡觉时仍会赚取的资产。金钱是我们转移时间和财富的方式。地位是你在社会层级中所处的位置。
	简评：财富是基础，有了财富，金钱和地位也随之可得
* 要理解有道德地创造财富是可能的。如果你暗地里鄙视财富，它就会躲避你。
	简评：反过来理解，创造财富有可能是以不道德的方式(比如劫掠、贪婪等等？)，但不是所有的方式都是不道德的，对财富需要有正确的认知，才可能获得财富。这可能和宗教有关。
* 无视那些玩儿地位游戏的人。他们通过攻击玩儿创造财富游戏的人来获得地位。
	简评：历史上多次出现过，其实也很难避免，最好的办法或许是成为或者扶植那些有地位的人
* 你不可能通过出租你的时间而致富。你一定要拥有股权--企业的一部分--来获得财务自由。
	简评：时间能换来金钱，但换不来财务自由
* 通过满足还没找到方法满足的社会需求而致富。要规模化。
	简评：关键词：潜在需求、规模化
* 挑选一个可以长期玩耍的行业，和此行业中可以长期共处的人。
	简评：足够的商业空间，稳定的合伙人
* 互联网极大地拓宽了职业的可能空间。大多数人还没意识到这一点。
	简评：互联网是创业首选之地，不过这应该是大多数人的共识了吧？真的还有人没有意识到这一点吗？
* 玩迭代的游戏。生活中所有的回报，无论是财富、关系还是知识，都来自[复利]。
	简评：要有\[\[复利思维]]，相信利滚利的力量，不怕增量小，但只要有增长，持续地增长，回报必定超出想象。积跬步以至千里。
* 挑选什么样的商业伙伴？高智商，正能量，以及，最最重要的，诚信。
	简评：反过来说，不诚信，负能量和愚蠢的人，不值得合作。我自己的观点，背叛一次的人，不再信任，永不合作。
* 不要与愤世嫉俗者和悲观主义者合作。他们的信念是自我实现的。
	简评：存疑。(信念导致信念的结果)
* 学会销售，学会建设，如果你两样都能做到，将不可阻挡。
	简评：一个人做到这两样很难，所以需要伙伴
* 用专有知识、责任心和[杠杆]来武装自己。
	简评：三把武器
* **专有知识就是你无法通过培训获得的知识。如果培训能得到的，其他人也能得到，从而取代你。**
	简评：专有，就是你有而别人没有的；想办法让自己具有不可替代性
* 专有知识，来自你真正的好奇心和激情，而不是那些流行热点
	简评：流行的东西总像浮云，经不住考验
* 积累专有知识对你来说就像游戏，但对其他人来说却像工作。
	简评：学习自己喜欢的、热爱的，才会轻松、愉快而专注
* 专有知识是以学徒方式传授的，而不是学校。
	简评：学校传授大众知识，而专有知识只能靠自己，这也是别人拿不走的
* 专有知识常常是高度技术性或创造性的，无法外包或自动生成。
	简评：高门槛
* 负有责任心，以自己的名义承担商业风险。社会将用信赖、股权和杠杆来回报你。
	简评：如果你是领导者，这是必须的，无论有没有回报
* 最有责任感的人拥有单一的、公开的、有风险的品牌：如奥普拉、特朗普、坎耶、伊隆。
	简评：特朗普……
* “给我一根足够长的杠杆，和一个支点，我将撬起地球。”-阿基米德
	简评：杠杆原理
* 财富需要杠杆。商业杠杆来自于资本、人员和没有边际复制成本的产品（如代码和媒体）。
	简评：请记住：人、财、物(产品)
* 资本即金钱。为了筹集资金，要运用你的专有知识，要有责任心，并表现出由此产生的良好判断力。
	简评：融资能力。用自己的钱行不行？在小生产时代是可以的，但在现代工业社会，不行。
* 劳动力即为你工作的人。这是最古老也是最容易被争夺的杠杆形式。劳动力杠杆会让你的父母印象深刻，但不要浪费生命去追逐它。
	简评：团队很重要，但，也没有那么重要，求质量，不求数量。
* 资本和劳动力是有许可限制的杠杆。每个人都在追逐资本，但必须有人把它给你。每个人都在试图领导团队，但必须有人跟随你。
	简评：资本和劳动力，都来自外部，需要争取。
* 代码和媒体是无须许可的杠杆。它们是新富群体背后的杠杆。即使在睡觉时你也可以创造出为你工作的软件和媒体。
	简评：产品是自己的，为什么是代码和媒体这类产品？因为它们可以随时随地地为你赚钱。
* 有一支机器人大军是可以自由使用的--它只是为了散热和空间效率而挤在数据中心里。好好利用它。
	简评：数据，数据，大数据。
